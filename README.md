# USSD Codes BD

Everyday USSD & mobile-banking codes in Bangladesh — dial or copy in one tap.
Fully offline, bilingual (English / বাংলা), no account, no network requests.

## Problem

Bangladeshis dial USSD codes every day — bKash (`*247#`), Nagad (`*167#`),
balance checks, emergency balance — but the codes live in scattered memory,
old screenshots, or operator leaflets. This app puts the codes people
actually use in one searchable, offline place, with one-tap dialling and a
way to save your own codes.

## Features

- **19 built-in codes** — bKash, Nagad, Rocket, Upay, SureCash menus; Grameenphone,
  Robi, Airtel, Banglalink and Teletalk self-care menus, balance checks,
  emergency balance and own-number codes.
- **Search** across code, service, title and description (English + বাংলা),
  multi-word AND, case-insensitive; bare digits match inside codes (`247` → `*247#`).
- **Category filters** with counts: Mobile banking, Grameenphone, Robi, Airtel,
  Banglalink, Teletalk.
- **One-tap dial** (`tel:` link, `#` percent-encoded so the dialler gets the
  full code) and **copy** with toast feedback.
- **Favourites** in localStorage, with a favourites-only view.
- **Add your own code** — validated (`*` … `#`, digits only), duplicate-checked,
  deletable, marked with a Custom badge.
- **Export / import / erase** your favourites and custom codes as JSON.
- **EN / বাংলা toggle** persisted, Bengali digits in counts, 390px mobile layout,
  zero network requests.

## Honesty note

Codes are commonly published USSD menus and **can change** — the footer and
this README say so, and the app tells users to verify with their operator or
bank before relying on a code. Dialling a code is free; services inside a
menu may charge. Nothing here is presented as an official operator listing.

## Stack

Vanilla HTML/CSS/JS, no dependencies, no build step. Data lives in
`js/data.js` (generated by `.scratch/gen.py`, Bengali as `\uXXXX` escapes so
all shipped sources stay pure ASCII); DOM-free logic in `js/logic.js` is
shared by the browser and the Node tests.

## Prerequisites

Any modern browser. For tests: Node.js 18+.

## Install & run

```sh
# open index.html directly, or serve the folder:
python3 -m http.server 8000
# then visit http://localhost:8000
```

No install step, no environment variables, no secrets.

## Testing

```sh
node tests/logic.test.js   # 56 unit tests (bank, search, validation, tel URI, import)
node tests/smoke.js        # 41 headless-Chrome checks via raw CDP (headless_shell)
```

## Deployment

Static site — GitHub Pages (main branch, root) or any static host.

## Limitations

- Built-in codes are a curated starter set, not an exhaustive operator catalogue.
- `tel:` dialling works on phones; on desktop it depends on the OS dialler.
- Clipboard copy falls back to a manual-copy hint where the Clipboard API is unavailable.
- Data (favourites, custom codes) lives in this browser's localStorage only.
